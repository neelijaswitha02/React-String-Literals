
# React Program Using String Literals

## Aim
To write a React program to display text using string literals.

## Description
- Template literals use backticks and ${} syntax.
- They allow embedding expressions and variables.
- They simplify dynamic message construction.
- They improve JSX readability.

## Output
Using String Literals

Hello, my name is jaswitha and I am 20 years old.

Welcome jaswitha! You are 20 years old.
